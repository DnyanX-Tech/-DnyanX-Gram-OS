## 💻 हे कसे चालवायचे? (How to Run)

1. थेट तुमच्या ब्राउझरमध्ये `index.html` फाईल उघडा (डबल-क्लिक करून).
2. किंवा लोकल सर्व्हर सुरू करण्यासाठी:
   ```bash
   python -m http.server 3000
   ```
   आणि ब्राउझरमध्ये `http://localhost:3000` उघडा.

# 💎 DnyanX परिवार (India''s First Family Operating System)

> "एक ॲप, एक कुटुंब, एक सबस्क्रिप्शन" — व्यापारी, ज्येष्ठ, शेतकरी आणि तरुण या सर्वांचा एकत्र डिजिटल सोबती.

---

## 🚀 Phase 1 मध्ये काय तयार झाले आहे?

### 1. MODULE 1: परिवार Setup (Family Profile & Member Roles)
- **Family Head & Profile:** कुटुंबाचे नाव, गाव/पत्ता, मुख्य संपर्क क्रमांक जतन करणे.
- **Member Directory:**
  - 👨‍💼 **वडील / व्यापारी** → Business OS सक्रिय
  - 👴 **आजोबा / आजी** → आठवण (आरोग्य व औषध) सक्रिय
  - 🌾 **काका / शेतकरी** → हक्क (शासकीय योजना) सक्रिय
  - 👧 **मुलगी / तरुणी** → मन (मानसिक आधार) सक्रिय
- **नवीन सदस्य जोडणे:** नाव, वय, भूमिका, फोन आणि संबंधित मायक्रो-सर्व्हिसचे १-क्लिक ॲक्टिव्हेशन.

### 2. MODULE 2: Business OS (व्यापाऱ्यासाठी)
- **Purchase Order (PO) Generator:**
  - सप्लायरचे नाव व व्हॉट्सॲप नंबर.
  - डायनॅमिक आयटम यादी, संख्या (Qty), दर (Rate).
  - GST दर (0%, 5%, 12%, 18%, 28%) नुसार अचूक गणना.
  - **jsPDF Integration:** १-क्लिकमध्ये व्यावसायिक इनव्हॉईस PDF डाऊनलोड.
  - **WhatsApp Sharing:** सप्लायरच्या व्हॉट्सॲपवर पूर्व-स्वरूपित (Pre-formatted) खरेदी आदेश तात्काळ पाठवणे.
- **Stock Management (स्टॉक व्यवस्थापन):**
  - साठा शिल्लक संख्या, अलर्ट लेव्हल आणि विक्री किंमत.
  - कमी साठा असल्यास **'कमी साठा!' (Low Stock Warning)** चे तात्काळ अलर्ट.
  - नवीन वस्तू स्टॉकमध्ये जोडण्याची सुविधा.
- **Face Recognition Attendance (कॅमेरा हजेरी):**
  - वेबकॅम एकत्रीकरण.
  - AI Face Scanning ॲनिमेशन आणि वेळ, तारखेसह हजेरी नोंद (Check-in log).

### 3. MODULE 3: आठवण (Aathvan - Phase 2 LIVE)
- **ज्येष्ठ नागरिक आरोग्य व औषध वेळापत्रक:**
  - सकाळ, दुपार, रात्रीच्या गोळ्यांचे रिअल-टाइम स्मरण.
  - **"हो घेतली ✅"** आणि **"थोड्या वेळाने ⏰"** चे मोठे सोपे बटन्स.
  - नवीन औषध जोडण्याची सोय.
- **दैनिक पाणी ट्रॅकर (Hydration):**
  - दिवसात किती ग्लास पाणी पिऊन झाले त्याची नोंद (+१ ग्लास बटण).
- **मराठी व्हॉईस AI सोबती:**
  - Web Speech API द्वारे मराठीत ऐकणे आणि मराठीत बोलणे (Voice Assistant).
  - आजोबांशी आपुलकीने गप्पा, गोष्टी आणि औषधांची चौकशी.
- **आपत्कालीन SOS व व्हॉट्सॲप ऑटोमेशन:**
  - लाल रंगाचे **"🚨 तातडीची मदत (SOS)"** बटण — दाबल्यास कुटुंबाच्या व्हॉट्सॲपवर अचूक पत्त्यासह त्वरित सुरक्षा संदेश पाठवणे.

### 4. MODULE 4: हक्क (Haqq - Phase 3 NOW LIVE!)
- **शेतकऱ्यांसाठी AI शासकीय योजना शोधक:**
  - नमो शेतकरी महासन्मान निधी + PM-KISAN (₹ १२,००० रोख मदत).
  - मागेल त्याला ठिबक सिंचन (८०% अनुदान).
  - महाकृषी यांत्रिकीकरण (ट्रॅक्टर व अवजारे ₹ १.२५ लाखांपर्यंत सबसिडी).
  - १ रुपयात पीक विमा योजना (१००% नुकसान भरपाई संरक्षण).
  - मागेल त्याला सौर कृषी पंप योजना.
- **मराठी व्हॉईस सर्च:**
  - शेतकऱ्यांनी फक्त माईकवर बोलून योजना शोधण्याची सुविधा.
- **१-क्लिक अर्ज संदर्भ व व्हॉट्सॲप शेअरिंग:**
  - कागदपत्रांची संपूर्ण यादी आणि व्हॉट्सॲपवर पाठवण्याची थेट सोय.

## 💻 हे कसे चालवायचे? (How to Run)

1. थेट तुमच्या ब्राउझरमध्ये `index.html` फाईल उघडा (डबल-क्लिक करून).
2. किंवा लोकल सर्व्हर सुरू करण्यासाठी:
   ```bash
   python -m http.server 3000
   ```
   आणि ब्राउझरमध्ये `http://localhost:3000` उघडा.
